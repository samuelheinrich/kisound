# SoundCloud Upload Data

This folder contains prepared metadata for manually uploading `Network Engineer` to SoundCloud.

Use `soundcloud_upload_sheet.md` as the copy/paste checklist in the SoundCloud web UI.

Recommended workflow:

1. Upload each WAV manually.
2. Set visibility to `Private` first.
3. Copy title, description, genre and tags from the sheet.
4. Add track artwork if available from `../xx_cover/` or the matching track folder.
5. After upload, paste the SoundCloud URL into `soundcloud_urls.md`.
6. Create a SoundCloud playlist named `Network Engineer` and order tracks from `00` to `09`.

Do not commit tokens, cookies, exported browser sessions or OAuth credentials here.
