[Verse 1]
A setting's missing from the menu, no checkbox, no switch,
the docs say: registry. I know the path without a hitch.

a tree of keys, and any branch can be a trap, and steep.
Before I change a thing: right-click, Export, save,
a .reg file as my backup, in case I misbehave.
New DWORD, thirty-two bit, the name exactly as it's shown,
value zero to one, I check it twice before it's done.
