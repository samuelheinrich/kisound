# Network Engineer 02

Second album in the Network Engineer series. Eight tracks follow the people and
systems behind a working network: the on-call engineer, an active/standby pair,
TrustSec policies, broadcast loops, packet traces, ICMP's underestimated power,
traffic classes and the independent management path used to recover access.
Each scene shapes its own electronic style. CLI and Microburst are archived.

**Language: German.** Lyrics are German with networking vocabulary in English.
TrustSec retains its German lyrics, English hooks and system messages.
YouTube descriptions and audio/metadata language in `album.yml` are German.
Track titles, genre names and established networking tags retain their original spelling.

**Status: musically complete.** The eight final tracks are numbered `01` through
`08`. Every track has an audio candidate and one retained lyric prompt.
All eight lyric prompts are version `1.0`, have status `Final` and name their
release WAV in `RELEASE AUDIO`. TrustSec's lyrics were reconstructed
from its existing transcripts after the original lyric file was found to contain
unrelated text. Its original style prompt is lost.

## Filenames and Retained Versions

Track folders use `NN_Track_Name`, starting at `01`. Lyric and audio filenames
share the track number, normalized title and lyric version:

```
02_Active_Standby/
  02_Active_Standby_1.0.txt
  02_Active_Standby_1.0.wav
  02_Active_Standby_1.0_cover.png
  02_Active_Standby_0.4_commercial_license.pdf
```

Spaces, slashes and colons in public titles become underscores in filenames.
Commercial licenses retain their original versioned filenames with
`_commercial_license`; the audio bytes are unchanged.
Support files use `NN_Track_Name_Transkript.*` and `NN_Track_Name_Video.md`.
Version numbers are internal production markers and are not public track titles.

An explicit lyric version in the original audio filename determines which text
is retained. If the audio filename has no version, the newest available lyric
version is used. Active / Standby's audio explicitly named `0.4`, so its `0.4`
prompt is retained and versions `0.2`, `0.3` and `0.5` have been deleted, together
with the separate Suno `0.5` field copies. Its monitor heartbeat and flatline
concept remain in the retained prompt. All other active tracks had one prompt.
The extensionless Active / Standby download was verified as WAV and now has the
`.wav` extension. The eight active lyric prompts, WAVs and track covers are now
version `1.0`. Renaming does not re-encode the audio.

## Two-Voice Tracks

- **Active / Standby:** Voice A is the deep male voice and Voice B the clear
  female voice. Each voice stays with its device. After heartbeat-link loss,
  both claim Active. In the finale the female voice is Active and the male
  voice Standby. Monitor beeps become a flatline on link loss and return with
  the restored heartbeat.
- **QoS:** Voice A is an urgent female voice for real-time traffic; Voice B
  is a relaxed deep male voice for bulk transfer. Their dialogue contrasts
  classification, queues, policing and shaping.
- `Voice A`, `Voice B` and `Both Voices` assign sections and must not be sung.

## Release Steps

The YouTube release uses animated cover videos for all eight tracks, including
TrustSec. The separate code-based TrustSec preview is not used in this release.
The renderer produces eight 1080p25 track videos, a full-album video and nine
1280x720 thumbnails in `xx_youtube/`. The metadata generator produces German
descriptions, measured album chapters and a manifest with nine private videos.
Only the eight individual tracks are inserted into the private playlist.

All album-specific settings live in `album.yml`. The release pipeline reads
final `*_1.0.txt` prompts and their named release WAVs.

```sh
script/clean_macos_file_metadata.rb Network-Engineer-Album02
script/tag_album_wavs.rb Network-Engineer-Album02
script/export_album_mp3_flac.rb Network-Engineer-Album02
script/build_album_videos.rb Network-Engineer-Album02
script/build_youtube_metadata.rb Network-Engineer-Album02
script/youtube/.venv/bin/python script/youtube/upload_youtube.py Network-Engineer-Album02
```

For upload preparation, stop after the metadata step and validate locally:

```sh
script/youtube/.venv/bin/python script/youtube/upload_youtube.py Network-Engineer-Album02 --dry-run
script/youtube/.venv/bin/python script/youtube/upload_youtube.py --check-auth
```

The dry run validates local video/thumbnail files without API calls or upload state
changes. The authentication check verifies the connected channel without uploading.
All nine videos were uploaded privately on 5 October 2026 to **samuel heinrich**,
with thumbnails and German metadata. The eight individual tracks are in the
[album playlist](https://www.youtube.com/playlist?list=PLZQEZ5jMLFzU); the
[full-album video](https://youtu.be/djsJnmmtXAE) is separate.
All links are recorded in [youtube_urls.md](xx_youtube/youtube_urls.md), and
`upload_state.json` preserves upload progress. The track videos have finished
YouTube processing; the album video was still processing at the API verification.
SRT subtitle files remain available locally and were not uploaded.
