# 03 · SHIP IT — COMMIT IT. SHIP IT.

Finale Suno-V3-Fassung in Deutsch und Englisch. Hard Phonk / Industrial Bass, 140-BPM-Ziel. Eine tiefe raue Stimme führt durch den Release von Album drei auf der eigenen Website. Die tatsächlichen Zeitmarken stehen in den Transkripten und Audioanalysen unter `final/de/` und `final/en/`.

## Handlung und Objekte

Neue Tracks und Cover liegen im Musikordner. `npm run build` erzeugt die Seiten; `npm run check` meldet danach einen fehlenden Coverpfad. Ein zusätzlicher Unterstrich im Dateinamen wird korrigiert. Erst der erneut fehlerfreie Check gibt den Deploy frei. Nach dem Upload zeigt der Browser noch den alten Cache-Stand. Ein harter Reload macht Album drei sichtbar. Deutsch und Englisch werden einzeln geprüft, die Lyrics behalten ihre jeweilige Originalsprache. Der öffentliche Player spielt die Veröffentlichung.

Die Hook **COMMIT IT. SHIP IT. / Build. Check. Live. / COMMIT IT. SHIP IT. / Album drei / three** ist ein Release-Slogan. Die Verse zeigen den tatsächlichen Ablauf. Build, Check, Upload und sichtbare Live-Seite bleiben getrennte Zustände.

## Technische Kontinuität

Der Dateifehler ist ein reproduzierbarer Pfadvergleich. `npm run build` kann bestanden sein, während `npm run check` den fehlenden Coverpfad findet. Nach der Korrektur wird der Check wiederholt. Der Deploy beginnt erst danach. Die Upload-Anzeige zeigt Cover, Audio und Texte separat; ein grüner Upload ersetzt die Browserprüfung nicht.

Der alte Browserstand kommt aus dem Cache. Ein harter Reload lädt den neuen Stand. DE und EN haben getrennte UI-Texte und eigene Original-Lyrics. Beim Play-Klick wird keine zweite Musikquelle zugemischt; die Filmtonspur ist die unveränderte finale WAV der gewählten Sprachfassung.

Zeiten, Einsätze und gemessene Akzente folgen den jeweiligen finalen WAVs. Das [Astra-Drehbuch](../_video_handoff/Vibecoder/03_SHIP_IT/ASTRA-DREHBUCH.md) führt beide Fassungen mit eigenen Zeitmarken aus.
